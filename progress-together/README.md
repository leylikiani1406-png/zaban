# Progress Together ♥ — اپ مشترک یادگیری انگلیسی
## اجرا
1. Node.js 18+ نصب باشد.
2. `npm install`
3. فایل `.env.example` را به `.env` کپی و مقداردهی کنید (SECRET و DATABASE_URL).
4. `npm start` ← http://localhost:3000
بدون DATABASE_URL، داده‌ها در data/db.json ذخیره می‌شود. جدول PostgreSQL خودکار ساخته می‌شود.
## Runflare / سرور
با Dockerfile همراه پروژه دیپلوی کنید؛ متغیرهای محیطی را در بخش «تنظیم متغیر محیطی» بگذارید. پورت: 3000.
## امکانات
- ثبت‌نام/ورود چندکاربره، پیشرفت جدا برای هر نفر
- تمرین روزانه: ۲۰ مبحث گرامر (۱۲ زمان، ۵ شرطی، مجهول، modal، نقل‌قول) + لغات
- «یاد گرفتم» (مرور با فاصله ۱،۳،۷،۱۴،۳۰ روز) یا «نیاز به تکرار» (نمایش ترفند ساده‌سازی)
- آزمون ۱۰ سؤالی
- افزودن لغت از Word (جدول ۴ ستونی)، PDF (نیاز به pdf-parse، متن‌دار)، یا paste
- مثال بیشتر: با ANTHROPIC_API_KEY هوشمند؛ بدون آن فقط جمله‌ی ساده
## نکته
بخش Speak، ترجمه‌ی پیام‌های چت و «More examples» نامحدود به ANTHROPIC_API_KEY نیاز دارند. مثال‌ها و ترجمه‌های داخلی گرامر و لغات آماده بدون کلید هم کار می‌کنند.
